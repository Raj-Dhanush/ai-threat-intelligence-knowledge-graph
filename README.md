# AI Threat Intelligence Knowledge Graph

## Overview
AI-powered cybersecurity intelligence platform that extracts entities and relationships from threat intelligence reports and visualizes them as a knowledge graph.

## Features
- User Authentication (JWT)
- PDF Upload and Parsing
- Entity Extraction
  - CVEs
  - Malware
  - Threat Actors
  - Countries
- Relationship Generation
  - exploits
  - uses
  - targets
- Interactive Knowledge Graph Visualization
- React Frontend + Node.js Backend

## Tech Stack

### Frontend
- React
- Vite
- React Flow

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- PDF-Parse

## Workflow

1. Upload Threat Intelligence PDF
2. Extract Text
3. Extract Entities
4. Generate Relationships
5. Visualize Knowledge Graph
